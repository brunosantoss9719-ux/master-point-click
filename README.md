# MASTER — Última Chamada

Thriller investigativo point-and-click 2D sobre o caso Banco Master. A campanha usa um sistema persistente de diligências — rastrear, verificar, confrontar e formalizar — com caminhos alternativos, conhecimento temporal e fail forward. O bônus **Copa 2022** permanece preservado fora do fluxo principal. Jogue em landscape.

```bash
npm start
```

Consulte `SOURCES.md` para a base factual e `PROJECT_STATE.md` para a retomada.
