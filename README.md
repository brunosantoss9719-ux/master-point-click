# MASTER — Última Chamada

Jogo narrativo point-and-click 2D sobre a crise do Banco Master, com 15 puzzles visuais em seis mecânicas e a campanha bônus **Copa 2022** baseada em registros públicos sobre o plano “Punhal Verde e Amarelo”. Jogue em landscape.

```bash
npm start
```

Consulte `SOURCES.md` para a base factual e `PROJECT_STATE.md` para a retomada.
